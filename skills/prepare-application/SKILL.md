---
name: prepare-application
description: Prepare or revise requested resume and cover letter packages for stable job IDs using the selected private career workspace. Does not submit applications.
---

Use this canonical procedure for requested materials, including requests routed by assistant adapters. Obtain the explicitly selected absolute `materials.json` path; load it with `tools.materials.workspace.load_workspace_config`. Do not use checkout-local career files or another person's configuration. Queue access requires its `instance_config_path`; D1 remains the hosted ledger. Verify the current posting and exact stable job ID before tailoring.

Read the selected career evidence and writing preferences. Run `load_evidence(config)` to confirm its reconciled digest. Latest direct corrections outrank earlier evidence, including the byte-exact source resume. If the candidate adds prose notes or corrections, reconcile them through [onboarding](../onboard/SKILL.md) before generating. Never infer unsupported career facts, authority, dates, metrics, scope, attribution, or contact fields. Ask only unresolved evidence gaps. Keep a claim-to-fact-ID review alongside generated content; missing terms from `check_terms` are suggestions only when the underlying work is supported.

Find existing packages with `existing_package.find(config.applications_root, job_id, company, title)`. `reserve_package(config, posting)` repeats discovery under the shared applications reservation lock and reuses an existing canonical latest version. If an exact-ID legacy package, ambiguous match, or name-only match exists in another folder, reservation stops for explicit resolution before allocating anything. Review that existing package; do not bypass the conflict by creating another directory. Preserve approved content and review receipts; a requested revision uses `new_version=True`. Package folders use stable job IDs and `vNNN`, never personal sequence floors or ticket numbers. Store posting, tailored `content.json`, optional `letter.json`, claim references, and reviews inside that package. Check its manifest `jobId` against the current posting before writing. A reserved package is `preparation_only`, not ready, approved, or submitted.

Render with the selected workspace's verified Python dependencies and reviewed fonts:

```
python -m tools.materials.render_resume --workspace-config /private/workspace/materials.json --content /private/workspace/applications/job/v001/content.json --out /private/workspace/applications/job/v001/resume.pdf
python -m tools.materials.render_letter --workspace-config /private/workspace/materials.json --content /private/workspace/applications/job/v001/letter.json --out /private/workspace/applications/job/v001/letter.pdf
```

Use actual resolved package paths. Skip letters when disabled. Missing dependencies or the selected font/license block completion. Default selection is macOS Arial; it never silently switches when absent. An explicit installed fallback is supported through `--font-family "Liberation Sans"` with per-command `MATERIALS_FONT_DIR=/absolute/installed/font-directory`. That directory must contain the reviewed unmodified `LiberationSans-Regular.ttf`, `LiberationSans-Bold.ttf` and `LICENSE_LIBERATION` from the [Mozilla PDF.js distribution](https://github.com/mozilla/pdfjs-dist/tree/master/standard_fonts). The resolver checks all three pinned hashes; other builds stop for fresh verification. This distribution accompanies the fonts with [SIL OFL 1.1](https://github.com/mozilla/pdfjs-dist/blob/master/standard_fonts/LICENSE_LIBERATION); no proprietary fonts are vendored. Fallback rendering/layout/independent text have been verified on macOS; repeat all document reviews for selected fonts and record the actual embedded family. No additional platform is advertised until its installation/document checks pass.

Run `measure_space`, `check_bullets`, and `verify_ats` on the real resume. Require the configured page count, no split bullets, and readable matching work history from pdfplumber and pypdf. Review bullet warnings. Measure each page's actual fill and unused space; add supported evidence before trimming or accepting avoidable empty space. Do not invent facts or shrink the reviewed typography to fill pages. Letter must be one page. Render every PDF page to PNG with Poppler and inspect every page for clipping, overlap, broken glyphs, margins, hierarchy, and readable spacing. A text-only check is insufficient.

Save an associated review receipt with job ID, version, evidence/writing-preference/content/PDF hashes, selected font family/font hashes/fallback license hash, page counts, measured fullness, bullet/ATS results and the visual inspection result. Record only completed checks, and show the candidate the package for review. Once the requested package passes these gates, `jobs_queue.set_status(job_id, "materials_ready", config.instance_config_path)` records preparation readiness. A `StatusMovedError` means the candidate's newer ledger action wins; keep the package and report the current state. Never infer a submission, submission timestamp, uploaded file version, or receipt from rendering or readiness. Applying, messaging employers, and recording an application need their own explicit user evidence/authorization.
